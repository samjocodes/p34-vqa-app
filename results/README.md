# Measured results

These files are produced by a **real evaluation run** — either the app's
*Evaluation and Report* tab, `python vqa_eval.py`, or `P34_colab_V2.ipynb`.
They are never hand-typed.

| File | What it is |
|---|---|
| `P34_report_Saumya_Joshi.pdf` | Full PDF project report (cover, U1–U5, five layers, results, failure study, responsible AI) |
| `results_summary.md` | Markdown tables of the same measured numbers |
| `results.json` | Raw per-pair record: question, ground truth, model answer, confidence, latency, expansions |

> If this folder is otherwise empty, the evaluation has **not** been run yet — do that
> before submitting (see the project README).
